Для запуска программ 1 и 2 нужно:
1) создать папку build
2) cd build && cmake .. && make
3) запуск 1 программы: ./program_1 (количество потоков) (количество точек)
4) запуск 2 программы: ./program_2 (t_end) (количество потоков) ../input.txt

Для запуска 3 программы предусмотрена папка for_test_3, внутри которой лежит:
1) prog_3.c - реализация rwlock
2) prog_3.h - заголовочный файл
3) pth_ll_rwl.c - тестирующий файл для собственной реализации rwlock
4) pth_ll_rwl_orig.c - тестирующий файл для библиотечной реализации rwlock
5) timer.h - используется для замера времени в каждой из трёх программ

Запуск 3 программы:
1) gcc pth_ll_rwl.c my_rand.c prog_3.c -o test - компиляция нашей реализации rwlock
2) gcc pth_ll_rwl_orig.c my_rand.c -o test_orig - компиляция библиотечной реализации rwlock
3) ./test (n_threads) - запуск
